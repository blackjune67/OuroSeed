# OuroSeed

Ouroboros Seed 1기에서 5주 동안 진행하는 실습, 결과물, 회고를 쌓는 학습 레포지토리입니다.

> 원칙: 한 주의 기록은 **무엇을 배웠는지**보다 **무엇을 만들어 보고, 어떻게 확인했고, 다음에 무엇을 바꿀지**가 남아야 합니다.

## 진행 현황

| 주차 | 주제 | 상태 | 핵심 산출물 |
| --- | --- | --- | --- |
| 1주차 | 에이전틱 워크플로우 기초 | 진행 중 | 첫 실습 기록, 나만의 요청 템플릿 |
| 2주차 | 하네스와 스킬 | 예정 | 재사용 가능한 규칙 또는 스킬 |
| 3주차 | 브라우저 에이전트 | 예정 | 조회·수집 자동화 실습 |
| 4주차 | 자동화 루프 | 예정 | 반복 실행 가능한 워크플로우 |
| 5주차 | 멀티 에이전트와 공유 | 예정 | 완성 워크플로우와 발표 기록 |

## 구조

```text
.
├── weeks/                 # 주차별 실습의 단일 출처
│   └── week-XX-topic/
│       ├── README.md       # 목표, 체크리스트, 이번 주 결과
│       ├── exercises/      # 단계별 실습 코드·프롬프트·명세
│       ├── notes/          # 개념·시행착오·학습 노트
│       ├── artifacts/      # 스크린샷, 데모, 결과 파일의 설명
│       └── retrospective/  # 회고와 다음 주 준비
├── projects/              # 여러 주차에 걸친 개인 워크플로우
├── templates/             # 기록·회고·실습 시작 템플릿
├── resources/             # 외부 자료 링크와 참고 메모
└── docs/                  # 운영 규칙과 전체 커리큘럼
```

## 기록하는 법

1. 해당 주차의 `README.md`에서 이번 실습의 목표와 완료 기준을 먼저 적습니다.
2. 실습 하나당 `exercises/`에 `01-주제.md`처럼 파일을 만듭니다.
3. 결과물은 코드·프롬프트·스크린샷을 함께 남기고, 민감 정보는 제거합니다.
4. 실습이 끝나면 `retrospective/weekly-review.md`에 배운 점과 다음 행동 하나를 기록합니다.

새 기록은 [실습 템플릿](templates/exercise.md)과 [주간 회고 템플릿](templates/weekly-review.md)을 복사해 시작합니다.
