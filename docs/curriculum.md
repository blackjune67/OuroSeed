# 5주 학습 로드맵

참고 발표의 에이전틱 워크플로우 흐름을 5주 실습 단위로 정리한 초안입니다. 실제 세션 내용이 달라지면 각 주차 README를 우선해 갱신합니다.

| 주차 | 질문 | 실습 초점 | 주차 종료 시 남길 것 |
| --- | --- | --- | --- |
| 1주차 | AI에게 일을 제대로 맡기려면? | 역할·목표·맥락·형식·기준을 갖춘 요청 | 첫 실습 기록과 요청 템플릿 1개 |
| 2주차 | AI 결과를 어떻게 일관되게 만들까? | 개인 규칙, 스킬, 검증 기준 | 재사용 가능한 하네스 또는 스킬 1개 |
| 3주차 | 브라우저에서 반복하는 일을 무엇부터 맡길까? | 로그인 사이트 조회, 자료 수집, 결과 정리 | 안전한 읽기 중심 워크플로우 1개 |
| 4주차 | 반복 업무를 어떻게 계속 돌릴까? | 실행 주기, 실패 알림, 복구 방법 | 자동화 루프와 운영 체크리스트 |
| 5주차 | 여러 에이전트를 어떻게 나눠 쓰고 검토할까? | 역할 분리, 결과 검토, 데모 | 완성 워크플로우와 공유 자료 |

## 공통 완료 기준

- 목표와 입력·출력을 한 문장으로 설명할 수 있다.
- 실제로 한 번 이상 실행한 증거가 있다.
- 결과를 확인한 방법과 남은 한계를 기록했다.
- 다음 개선 행동이 하나 이상 있다.
