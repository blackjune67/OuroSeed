# 1주차 · 에이전틱 워크플로우 기초

상태: 진행 중
시작일: 2026-11-15

## 이번 주 질문

AI에게 맡길 일을 모호한 부탁이 아닌, 확인 가능한 작업으로 어떻게 설명할까?

## 목표

- 역할·목표·맥락·형식·기준을 포함한 요청을 직접 작성한다.
- 작은 업무 하나를 AI와 끝까지 수행하고 결과를 확인한다.
- 다음에도 쓸 수 있는 나만의 요청 템플릿을 남긴다.

## 실습 체크리스트

- [ ] 실습할 실제 업무 하나를 고른다.
- [ ] [첫 실습 기록](exercises/01-first-practice.md)을 채운다.
- [ ] 결과물을 직접 확인하고 한계도 적는다.
- [ ] [주간 회고](retrospective/weekly-review.md)를 작성한다.

## 폴더 안내

- `exercises/`: 실행 순서, 프롬프트, 코드 및 결과
- `notes/`: 개념, 팁, 막힌 지점
- `artifacts/`: 스크린샷·데모·결과물 설명
- `retrospective/`: 주간 회고 및 다음 주 준비

## 완료 기준

실제 업무 또는 개인 과제 하나에 대해, 요청·실행 결과·확인 방법·다음 개선점이 모두 기록되어 있으면 완료입니다.
